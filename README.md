# Freznel AI — Web Store Assessment

A Steam-inspired web-store interface built for the Freznel AI JavaScript Developer assessment.

## Tech Stack

* React
* Vite
* Tailwind CSS
* Firebase Authentication
* TMDB API
* GSAP / CSS animations

## Features

* Steam-inspired store, search, and exploration pages
* TMDB-powered movie content
* Search, filtering, sorting, and pagination
* Lazy-loaded images
* Offline caching with localStorage
* Online/offline connection status
* Firebase email/password signup
* Responsive and keyboard-accessible UI

## Run Locally

```bash
npm install
npm run dev
```

Create a `.env` file using `.env.example` and add the required TMDB and Firebase credentials.
